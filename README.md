# FeelTrack
Analisi del sentiment dei post sui social attraverso tecniche di NLP e Machine Learning 
FeelTrack — Social Sentiment Analysis

Descrizione

FeelTrack è un progetto di Sentiment Analysis sviluppato nell'ambito dello studio dei Fondamenti di Intelligenza Artificiale.

L'obiettivo del progetto è analizzare automaticamente il sentimento espresso all'interno di post testuali provenienti dai social network, utilizzando tecniche di Natural Language Processing (NLP) e Machine Learning.

Il progetto segue una pipeline di elaborazione che parte dalla preparazione e dal preprocessing dei dati testuali, prosegue con l'addestramento del modello e termina con la classificazione e l'analisi dei risultati ottenuti.

Obiettivi

- Analizzare dati testuali provenienti dai social network.
- Applicare tecniche di Natural Language Processing.
- Preparare e preprocessare i dati prima dell'addestramento.
- Addestrare un modello per la classificazione del sentiment.
- Analizzare e valutare i risultati della classificazione.

Tecnologie utilizzate

- Python
- Natural Language Processing (NLP)
- Machine Learning
- Jupyter Notebook

Struttura del progetto

Il repository contiene il notebook:

"FeelTrack.ipynb"

Il notebook raccoglie le principali fasi del progetto:

1. Importazione e preparazione dei dati
2. Preprocessing del testo
3. Elaborazione dei dati
4. Addestramento del modello
5. Classificazione del sentiment
6. Analisi dei risultati

Contesto

Il progetto è stato realizzato nell'ambito dello studio dei Fondamenti di Intelligenza Artificiale.
L'attività ha permesso di applicare concetti di Intelligenza Artificiale e Natural Language Processing a un caso d'uso legato all'analisi automatica dei contenuti testuali pubblicati sui social network.
